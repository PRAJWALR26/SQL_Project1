# Online Retail Database Management System

## Project Overview

This project demonstrates the design and implementation of a relational database for a fictional online retail company using Microsoft SQL Server.

The database, **OnlineRetailDB**, manages customer information, product inventory, product categories, customer orders, and order details. It also includes various SQL queries for reporting, data analysis, and CRUD operations.

---

# Objectives

* Design a normalized relational database.
* Establish relationships using primary and foreign keys.
* Insert sample business data.
* Perform data retrieval and analysis using SQL queries.
* Demonstrate CRUD (Create, Read, Update, Delete) operations.
* Generate business reports using joins, aggregations, subqueries, and ranking functions.

# Database Schema

## 1. Customers

Stores customer information.

### Columns

* CustomerID (Primary Key)
* FirstName
* LastName
* Email
* Phone
* Address
* City
* State
* ZipCode
* Country
* CreatedAt

---

## 2. Categories

Stores product category information.

### Columns

* CategoryID (Primary Key)
* CategoryName
* Description

---

## 3. Products

Stores product details and inventory information.

### Columns

* ProductID (Primary Key)
* ProductName
* CategoryID (Foreign Key)
* Price
* Stock
* CreatedAt

---

## 4. Orders

Stores customer order information.

### Columns

* OrderID (Primary Key)
* CustomerID (Foreign Key)
* OrderDate
* TotalAmount

---

## 5. OrderItems

Stores individual items included in each order.

### Columns

* OrderItemID (Primary Key)
* OrderID (Foreign Key)
* ProductID (Foreign Key)
* Quantity
* Price

---

# Entity Relationship Overview

Customers
|
|-- Orders
|
|-- OrderItems
|
Products ----- Categories

### Relationships

* One Customer can place many Orders.
* One Order can contain multiple OrderItems.
* One Product can appear in many OrderItems.
* One Category can contain multiple Products.
